# Заправочная станция

__Описание:__ система учета топлива на заправочной станции.

__Задача__ Есть некая заправочная станция с разными видами ГСМ (бензин, солярка, дизель) и есть резервуары с их запасами. В течении дня через нее проходят разные автомобили и нужно проверять их уровень топлива, если он ниже критического минимума тогда нужно его пополнять и фиксировать этот расход из резервуара.
